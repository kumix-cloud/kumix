# Kumix — Issues & Feature Requests

Public tracker for [Kumix.cloud](https://kumix.cloud), the platform for managing your VPS servers, websites and apps from one dashboard.

This repository holds **no source code**. Use it to:

- 🐞 **Report a bug** — something is broken or behaves unexpectedly
- 💡 **Request a feature** — an idea or improvement you'd like to see
- ❓ **Account or billing questions** — email support@kumix.cloud (keeps your details private)

👉 **[Open a new issue](https://github.com/kumix-cloud/kumix/issues/new/choose)**

---

## Before you open an issue

1. **Search first.** Check [open and closed issues](https://github.com/kumix-cloud/kumix/issues?q=is%3Aissue) to see if it was already reported. If it was, add a 👍 reaction or a comment with extra details rather than opening a duplicate.
2. **One issue per report.** Split unrelated problems into separate issues so they can be tracked and closed independently.
3. **Use the templates.** They ask for the information we need to reproduce and fix the problem quickly.

## ⚠️ Never post sensitive data

Issues are **public**. Do not include:

- Passwords, API tokens, SSH private keys or `.env` contents
- Server IP addresses, root credentials or database dumps
- Personal data of you or your customers

If we need private details, we'll ask you to email them to support. Redact screenshots and logs before uploading.

## 🔒 Security vulnerabilities

**Do not report security issues here.** Email **security@kumix.cloud** with a description and steps to reproduce. We'll acknowledge your report and keep you updated until it's resolved.

## What helps us fix bugs faster

- Clear steps to reproduce, starting from a known page or action
- What you expected vs. what actually happened
- Screenshots or screen recordings (redacted)
- The server OS (e.g. Ubuntu 24.04) if the issue involves a VPS, site or app
- Browser and version if the issue is in the dashboard UI
- Approximate date/time (with timezone) the problem occurred

## Issue lifecycle

| Label | Meaning |
|-------|---------|
| `bug` | Confirmed or reported defect |
| `enhancement` | Feature request or improvement |
| `needs-info` | Waiting on more details from the reporter |
| `confirmed` | Reproduced by the team |
| `planned` | Accepted and scheduled |
| `wontfix` | Out of scope or not planned |

Issues labelled `needs-info` with no response for 14 days may be closed. You can always reopen with new details.
